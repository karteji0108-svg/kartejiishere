# Changelog

## [1.5.0] - 2026-02-16

### 🎉 Apa yang Baru (What's New)

#### 🌙 Spesial Ramadan
*   **Jadwal Imsyakiyah Akurat:** Menampilkan jadwal sholat sesuai lokasi Anda (GPS) dengan nama kota/kecamatan otomatis.
*   **Tema Ramadan:** Hiasan visual bulan sabit dan nuansa warna khusus (bisa dimatikan di Profil).

#### 📱 Pengalaman Pengguna (UX)
*   **Install Aplikasi:** Tombol "Install" otomatis muncul untuk menambahkan aplikasi ke Layar Utama (Home Screen).
*   **Login Otomatis:** Tidak perlu login ulang jika aplikasi ditutup (Persistent Login).
*   **Perbaikan Profil:** Memperbaiki masalah crash saat membuka profil dan gagal ubah foto/nama.

#### 💰 Keuangan
*   **Format Rupiah:** Input uang sekarang otomatis ada pemisah ribuan (titik) agar mudah dibaca.
*   **Tampilan Bersih:** Menghapus chart "Arus Kas" untuk tampilan yang lebih simpel dan fokus.

#### ⚡ Performa & Keamanan
*   **Lebih Cepat:** Aplikasi memuat lebih cepat berkat optimasi kode (Lazy Loading).
*   **Lebih Aman:** Peningkatan keamanan pada sistem login dan penyimpanan data.
